# Railway Deployment Configuration

# Questo file configura il deployment per Railway.app
# Railway rileva automaticamente applicazioni Node.js

# Le variabili d'ambiente necessarie sono:
# - DATABASE_URL (fornito automaticamente da Railway per PostgreSQL)
# - JWT_SECRET 
# - ENCRYPTION_KEY
# - NODE_ENV=production

# Railway eseguirà automaticamente:
# 1. npm install
# 2. npm start

# Il database PostgreSQL è fornito come addon
